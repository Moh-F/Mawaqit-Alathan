# Changelog

## 1.0.0
- Custom-drawn prayer times screen for Google TV / Fire TV (Fire OS 6+, Android 7.0+)
- Times from your mosque page on mawaqit.net, calculated times (Aladhan) as fallback, offline cache
- Everything adjustable: layout, sizes, colors, spacing, corner radius, digits, language, themes
- Phone control and live log viewer on the home network (off by default)
- In-app updates via GitHub Releases (same signature = installs over the old version, data kept)
- Splash with progress, version ribbon, Arabic (RTL) / English / German
